# Гроші — особистий бюджет

Веб-застосунок (PWA) для розподілу зарплати та інших надходжень по категоріях,
відстеження перекидання коштів у банк, позик між категоріями та статистики.
Дані зберігаються локально в браузері (localStorage).

## Розробка

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```

Стек: React + TypeScript + Vite, Tailwind CSS v4, Zustand (persist), Framer Motion, Recharts.
